## 0. الهدف

المرحلة 7 أسّست الهيكل المحايد الصحيح. المرحلة 8 لا تغيّر الهوية، بل ترفع **الإحساس بالأداة الاحترافية**: تسلسل بصري أدق، لوحات قابلة لإعادة التحجيم، حالات واجهة مكتملة، وتفاعلات دقيقة تجعل التطبيق يُقرأ كأداة تصميم مكتبية لا كواجهة ويب.

**قاعدة حاكمة:** لا تُضاف زينة. كل تغيير يجب أن يزيد وضوح المهمة أو يقلّل خطواتها أو يوضّح حالة النظام.

## 1. نطاق العمل

| المحور | القرار | نتيجة قابلة للتحقق |
|---|---|---|
| M1 — التسلسل البصري | توحيد مقاسات النص، الأرقام الجدولية، كثافة المسافات، وتدرّج وزن العناوين | لا توجد عناوين متساوية الحجم بأوزان مختلفة؛ كل readout رقمي mono/tabular |
| M2 — اللوحات Adobe-grade | إضافة فواصل قابلة للسحب والكيبورد للوحة المستند والمفتش | `role="separator"` مع `aria-valuenow`؛ ArrowKeys تضبط العرض |

| M4 — التفاعل | حالات hover/active/focus متسقة، tooltips ناعمة بلا توهّج، انتقالات تحترم reduced-motion | لا وميض، لا توهّج، لا حركة عند تقليل الحركة |
| M5 — الحالات | حالة فارغة موجّهة بخطوات، حالة بحث فارغة قابلة للإزالة، إشعارات نجاح/خطأ بدلالة صحيحة | `role="status"` للنجاح و`role="alert"` للخطأ؛ كل حالة فيها إجراء تالٍ |
| M6 — التحقق | اختبارات وحدة + Playwright + axe + لقطات أربع مقاسات | 0 violations، 0 console errors، لا overflow |

## 2. ما لا يتغيّر

- `dir="rtl"` و`lang="ar"` في `index.html`.
- الخصائص المنطقية CSS (`inset-inline-*`, `margin-inline-*`, `padding-inline-*`).
- هوية الخانة من المشروع، وليس من اسم ملف SVG.
- عقود Rust، منطق المحرك، التشكيل، المراسي، وحفظ المشروع.
- hooks الاختبار: `ws-tool-rail`, `ws-canvas-toolbar`, `ws-status-strip`, `خصائص الخانة`, `accordion`.
- ترتيب طيّات المفتش: الاستيراد → خصائص الخانة → خطوط القياس → المراسي → الأدلة → الشبكة والالتقاط → التحقق → السجل.
- اللغة البصرية: رمادي محايد، حواف 1px، أنصاف 2–4px، بلا تدرّجات أو زجاج أو توهّج أو pills زينة.

## 3. نظام المقاسات المعتمد

| الرمز | القيمة | الاستخدام |
|---|---:|---|
| `--fs-2xs` | 9px | وحدات المفتش، الفواصم |
| `--fs-xs` | 10px | التسميات، البيانات الوصفية |
| `--fs-sm` | 11px | عناصر التحكم، قوائم اللوحات |
| `--fs-md` | 12px | النص الأساسي |
| `--fs-lg` | 13px | عناوين اللوحات |
| `--fs-xl` | 15px | عناوين الحالات الفارغة |
| `--lh-dense` | 1.35 | رؤوس اللوحات والقوائم |
| `--lh-body` | 1.5 | النص العام |

الأرقام كلها تستخدم `font-variant-numeric: tabular-nums` عبر `--font-mono`.

## 4. معايير القبول

1. **بصرياً:** لا لون يلفت النظر قبل الشكل؛ الأزرق يبقى مقتصراً على focus/selection/active.
2. **وظيفياً:** كل فاصل قابل للسحب له بديل كيبورد، وكل حالة فارغة فيها إجراء واضح.
3. **وصولياً:** axe-core بلا مخالفات serious/critical على مقاس 1440×900 ولوحة المشروع.
4. **توافقياً:** لا overflow على 1440×900، 1280×800، 1024×768، 820×900.
5. **آلياً:** `npm test`, `npm run build`, `uv run --project engine pytest -q`, `cargo test --manifest-path src-tauri\Cargo.toml`, `git diff --check` كلها ناجحة.
